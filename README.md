# Hide YouTube Shorts List

A [uBlock Origin](https://github.com/gorhill/uBlock) filter list to hide all recommended YouTube Shorts.

A fork of [gijsdev/ublock-hide-yt-shorts](https://github.com/gijsdev/ublock-hide-yt-shorts) which hides all traces of Shorts.  
My version allows Shorts on channel pages and the Subscriptions page.

This filter list also works in AdGuard.

Copy the link below, go to uBlock Origin > Dashboard > Filter lists, scroll to the bottom, and paste the link underneath the 'Import...' heading:
- [https://raw.githubusercontent.com/momasta/ublock-hide-yt-shorts/master/list.txt](ubo:subscribe?location=https://raw.githubusercontent.com/momasta/ublock-hide-yt-shorts/master/list.txt)
